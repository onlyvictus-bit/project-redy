## Directory Purposes

**src/main/**
- Purpose: Core workbench logic running in Electron main process
- Contains: Application controller, services, connectors, utilities
- Key files: `app-controller.ts` (orchestrator), `services/workflow-engine.ts` (task execution)

**src/main/connectors/**
- Purpose: Abstract agent integrations for Claude, Codex, Gemini, Ollama
- Contains: BaseConnector implementation, agent-specific subclasses
- Key files: `base.ts` (interface), individual connector implementations

**src/main/services/**
- Purpose: Domain-specific service implementations
- Contains: WorkflowEngine, WorkspaceManager, TerminalManager, PersistenceService, ProcessRunner, OllamaManager, ProjectArchiveService
- Key files: `workflow-engine.ts` (step orchestration), `workspace-manager.ts` (git management), `persistence.ts` (SQLite)

**src/main/utils/**
- Purpose: Shared utility functions
- Contains: Output parsing, path mapping (Windows/WSL), prompt templates
- Key files: `parsing.ts` (extract structured data), `path-mapping.ts` (cross-platform paths), `prompts.ts` (agent prompts)

**src/preload/**
- Purpose: IPC bridge between renderer and main
- Contains: Context bridge exposing WorkbenchApi to renderer
- Key files: `index.ts` (single file exposing API)

**src/renderer/src/**
- Purpose: React-based user interface
- Contains: App root, components, Zustand store, styling
- Key files: `App.tsx` (main layout), `store.ts` (state management), `components/` (UI building blocks)

**src/renderer/src/components/**
- Purpose: Reusable React components
- Contains: Agent panels, task cards, artifact viewers, terminal panes
- Key files: TaskDetailPanel.tsx, FindingsPanel.tsx, ArtifactViewer.tsx

**src/shared/**
- Purpose: Shared definitions used across main and renderer
- Contains: TypeScript types, IPC channels, workflow definitions
- Key files: `types.ts` (ProjectRef, TaskRun, AgentProfile), `ipc.ts` (channel names), `workflows.ts` (workflow list)

**out/**
- Purpose: Compiled JavaScript output (generated by build)
- Contains: Compiled main, preload, renderer bundles
- Generated: Yes, committed: No

## Key File Locations

**Entry Points:**
- `src/main/index.ts`: Electron main process entry, creates window, wires IPC
- `src/renderer/src/main.tsx`: React DOM render call
- `src/renderer/src/App.tsx`: Root React component

**Configuration:**
- `electron.vite.config.ts`: Vite configuration for main/preload/renderer builds
- `tsconfig.json`: TypeScript compiler options
- `package.json`: Dependencies and build scripts

**Core Logic:**
- `src/main/app-controller.ts`: Central orchestrator managing all operations
- `src/main/services/workflow-engine.ts`: Multi-agent task orchestration
- `src/main/services/workspace-manager.ts`: Git worktree and diff management
- `src/renderer/src/store.ts`: Zustand state management for UI

**Data Persistence:**
- `src/main/services/persistence.ts`: SQLite database layer
- Database location: `${app.getPath('userData')}/triad-workbench.db`

**Testing:**
- `src/renderer/src/test-setup.ts`: Vitest configuration
- `src/renderer/src/test-fixtures.ts`: Test data
- Test files: `*.test.tsx`, `*.test.ts` co-located with source

## Naming Conventions

**Files:**
- Service files: camelCase with `-manager` suffix (e.g., `workflow-engine.ts`, `terminal-manager.ts`)
- Connector files: camelCase with `-connector` suffix (e.g., `claude-connector.ts`)
- Component files: PascalCase (e.g., `TaskDetailPanel.tsx`)
- Utility files: camelCase (e.g., `parsing.ts`, `path-mapping.ts`)
- Test files: same name with `.test.ts` or `.test.tsx` suffix

**Directories:**
- Feature/domain directories: lowercase plural (e.g., `services`, `connectors`, `components`)
- Process-specific: lowercase (e.g., `main`, `preload`, `renderer`)

**Classes/Interfaces:**
- Classes: PascalCase (e.g., AppController, WorkflowEngine, ProcessRunner)
- Interfaces: PascalCase with optional `I` prefix (e.g., AgentConnector, TaskRun)
- Types: PascalCase (e.g., AgentId, AgentRole, WorkflowId)

**Functions/Variables:**
- camelCase (e.g., runJob, createTaskWorkspace, mapPathForRunner)
- Constants: UPPER_SNAKE_CASE (e.g., IPC_CHANNELS, DEFAULT_AGENTS)

## Where to Add New Code

**New Feature (Agent Integration):**
- Connector implementation: `src/main/connectors/{agent}-connector.ts`
- Extend `BaseConnector`, implement getScriptedCommand() and getInteractiveLaunchSpec()
- Register in `src/main/app-controller.ts` constructor connectors map
- Add to `AgentId` union type in `src/shared/types.ts`

**New Service/Domain Logic:**
- Create file: `src/main/services/{domain}-{type}.ts`
- Extend existing service pattern (constructor injection, public methods, private helpers)
- Import and instantiate in `src/main/app-controller.ts`

**New UI Component:**
- Location: `src/renderer/src/components/{ComponentName}.tsx`
- Pattern: Functional component with typed props, use `useWorkbenchStore()` for state
- Co-locate tests: `{ComponentName}.test.tsx`

**New Workflow Type:**
- Add WorkflowId union variant in `src/shared/types.ts`
- Add WorkflowDefinition entry in `src/shared/workflows.ts`
- Implement handler method in `src/main/services/workflow-engine.ts`
- Extend switch statement in WorkflowEngine.start()

**Utilities/Helpers:**
- Parsing logic: `src/main/utils/parsing.ts`
- Path mapping: `src/main/utils/path-mapping.ts`
- Prompt templates: `src/main/utils/prompts.ts`

**Data Structures:**
- All types: `src/shared/types.ts` (shared across processes)
- IPC channels: `src/shared/ipc.ts` (channel name constants)

## Special Directories

**out/:**
- Purpose: Compiled output directory
- Generated: Yes (built by electron-vite)
- Committed: No (in .gitignore)

**.triad-workbench/ (per project):**
- Purpose: Archive directory inside each project root
- Generated: Yes (created by ProjectArchiveService)
- Committed: No (in target project's .gitignore)
- Contains: Snapshots, prompts, logs, diffs, terminal transcripts

**node_modules/:**
- Purpose: Installed dependencies
- Generated: Yes (by npm/yarn)
- Committed: No (in .gitignore)
